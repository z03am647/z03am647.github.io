GitHub Pages + Jekyll でブログを始めました。

## 記事の書き方

`_posts/` フォルダに `YYYY-MM-DD-スラッグ.md` という名前のファイルを作るだけです。

```markdown
---
layout: post
title: タイトル
date: 2026-11-18
---
本文を Markdown で書く
```

ファイルは次の形式で名前を付けます:

- `2026-11-18-my-next-post.md`
- `_config.yml` でサイトのタイトルやナビゲーションを変更できます

GitHub に push すると数分で自動公開されます。
